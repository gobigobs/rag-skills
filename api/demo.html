What’s inside

Two Agent Skills, a runnable eval, and this live API — one pack, built from the evals above.

rag-build

Build a RAG pipeline, the measured way

Chunking → embedding → retrieval → rerank → abstention gate. The skill carries the decisions the evals earned: which chunk sizes held up, why the gate is content-word overlap and not an RRF threshold.

rag-eval

Evaluate honestly

Question sets, metrics, and how to read results without fooling yourself — including the findings that flipped between rounds.

scripts/eval.py

Zero-install eval harness

Pure stdlib. TF-IDF and BM25 run anywhere; SBERT and cross-encoder rerank are optional and skip cleanly if not installed. Never downloads a model.

api/main.py

Live demo API

GET /health · GET /results · POST /ask with a real abstention gate. This page is served by it.

data/results.json

Real numbers, kept intact

Full summaries for v2, v3 and v4 corpus-v2, extracted programmatically from the source evals — not retyped.

Quick start — 30 seconds

Three steps. No account, no key, no model download.

Copy the skills

Drop both skills into your agent’s skills folder.

cp -r skills/rag-* .claude/skills/

Run the eval

Pure stdlib — runs on the 4-doc sample corpus immediately.

python3 scripts/eval.py --chunking A

Try the API

Start the demo and ask it a question at the top of this page.

uvicorn api.main:app --port 8000
